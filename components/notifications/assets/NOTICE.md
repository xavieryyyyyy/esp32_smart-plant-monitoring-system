# Inline email mark

`plant-mark.svg` uses the Sprout icon from [Lucide](https://lucide.dev/icons/sprout), under the ISC license. The SVG was rendered to the transparent 64×64 `plant-mark.png`; its Base64 representation in `notification_format.c` is included in the email as an inline MIME attachment.

The applicable [Lucide license notice](../../../docs/assets/readme/LUCIDE-LICENSE.txt) is included in this repository. The mark is a presentation asset, not sensor/test evidence. No external image request is needed to display it.
